# 暴力决定

暴力决定是一款集合多种实用工具的移动端应用，基于 React、Vite 和 Capacitor 构建，目前支持 Android 平台。它的诞生源于一个简单的想法：把日常需要随机选择和快速决策的工具汇聚在一个应用中，既实用又有趣。

在功能方面，暴力决定提供了骰子投掷，支持一到六面，带有流畅的动画和震动反馈；自定义转盘可以自由编辑选项，适合各种随机选择场景；炸弹牌游戏则是一种多人互动的翻牌玩法，包含安全牌和炸弹牌的逻辑。此外还有指定范围的随机数生成，以及一个完整的绘图工作区，支持画笔、橡皮擦、调色板、撤销和保存功能。游戏板块整合了俄罗斯方块和超级马里奥，方便随时娱乐。近期新增的 BMI 计算器支持身体质量指数计算、历史记录、多档案管理、数据图表展示以及数据的导入导出。

界面设计上，暴力决定提供了亮色、深色和液态玻璃三种主题。液态玻璃材质采用了 blur 30px 配合 saturate 180% 的视觉效果，加上内高光和极轻的阴影，追求一种接近 iOS 和 VisionOS 的质感。所有组件使用统一的圆角体系，整体视觉效果较为克制和统一。

技术方面，应用基于 React 19 和 Vite 6 构建，使用 Tailwind CSS 处理样式，图表部分使用 Recharts，日期格式化使用 date-fns，公式渲染使用 KaTeX，P2P 通信部分引入 PeerJS。通过 Capacitor 封装为 Android 原生应用，一键构建即可生成 APK 安装包。

```bash
npm install
npm run dev     # 开发服务器
npm run apk     # 构建 Android APK
```
